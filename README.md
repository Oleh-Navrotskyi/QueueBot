# 🎓 Student Priority Queue Bot (Telegram)

Telegram-бот для керування електронною чергою на парах та захистах лабораторних робіт. Розв'язує проблему "живої черги" шляхом введення системи пріоритетів.

## 📌 Про проблему
Під час пар багато студентів намагаються здати роботи одночасно, що створює хаос. Крім того, класична черга (FIFO) не є ефективною: студент, якому потрібно за 30 секунд просто отримати завдання, змушений чекати годину, поки інші захищають звіти. 

Цей бот реалізує **пріоритетну чергу (Priority Queue)**: ті, кому потрібна швидка дія (наприклад, отримати завдання і піти працювати), автоматично потрапляють у початок списку.

## 🚀 Основний функціонал
- **Розумна черга (PriorityQueue):** Автоматичне сортування студентів за типом запиту.
- **Inline-кнопки:** Зручний вибір типу задачі (Завдання / Захист) без необхідності вводити текст вручну.
- **Збереження стану (Persistence):** Черга автоматично серіалізується у локальний файл (`queue.dat`). Якщо бот або сервер перезавантажиться, жоден студент не зникне зі списку.
- **Long Polling:** Бот не потребує налаштування Webhook чи виділеного сервера (може працювати локально з ноутбука викладача).
- **Стійкість до обривів мережі:** Налаштовані таймаути для стабільної роботи при нестабільному Wi-Fi з'єднанні.

## 🛠 Технологічний стек
- **Мова:** Java (24)
- **Бібліотека:** [TelegramBots API](https://github.com/rubenlagus/TelegramBots)
- **Зберігання даних:** Java Object Serialization (File I/O)
- **Збірка проекту:** Maven / Gradle

## 📱 Команди бота (Меню)
/reg [Прізвище] — встати в чергу.

/list — переглянути поточний стан черги.

/next — викликати наступного студента (команда для викладача).
